# 📚 GeeksforGeeks CSS Academic Scraper

A web-based system that scrapes CSS tutorials from GeeksforGeeks and generates professional PDF learning materials.

## Features
- Scrape CSS articles from GeeksforGeeks
- Extract titles, difficulty levels, key concepts, code snippets, and complexity analysis
- Generate professional PDF learning modules
- Filter and search scraped content
- Download generated PDFs
