# 🎮 Eurogamer Game Scraper

A web-based system that scrapes real-time game data from Eurogamer.net and displays it in a clean, organized interface with images.

![Eurogamer Scraper Demo](screenshot.png) *Add a screenshot of your app here*

## 📋 Features

- ✅ **Real-time Web Scraping**: Dynamically extracts game data from Eurogamer.net
- ✅ **Required Fields**: Game Title, Release Date, Key Features, Platform Availability, Developer, Publisher
- ✅ **Image Support**: Automatically extracts and displays game images (hotlinked from source)
- ✅ **CSV Storage**: All scraped data is saved to CSV format
- ✅ **JSON Backup**: Data also saved in JSON format
- ✅ **Web Interface**: Clean, responsive UI with search and filter functionality
- ✅ **Statistics Dashboard**: View platform and developer statistics
- ✅ **No Hardcoded Data**: All data is dynamically scraped - zero hardcoding

## 🛠️ Technologies Used

- **Backend**: Python 3.7+, Flask, BeautifulSoup4, Requests
- **Frontend**: HTML5, CSS3, JavaScript (ES6)
- **Data Storage**: CSV, JSON
- **Deployment**: Ready for local hosting or cloud platforms
